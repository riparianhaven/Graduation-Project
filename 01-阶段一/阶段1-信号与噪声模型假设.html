阶段 1 过关产物 2｜信号与噪声模型假设

用途：阶段 2 建模的输入、阶段 4 指标的基准；也是开题报告里"信号与噪声模型"那一段的直接底稿。

性质：假设文档，不是结论。所有数值都是"初设 + 依据 + 待替换"三件套，导师给实测数据后逐行替换即可。

核实日期：2026-11-19

一、一句话版本

本课题面对的输入是已知频率、未知幅值与初相的单频弱信号，叠加有色（$1/f^{\alpha}$）背景噪声与器件自身残余误差；检测问题形式化为 $H_0$（仅噪声）与 $H_1$（信号 + 噪声）的二元假设检验，指标报 $P_d$、$P_{fa}$ 与参数估计误差，全部连实验条件一起报。

二、信号模型

$$
s(t)=\gamma\cos(\omega t+\theta),\qquad t\in[0,T]
$$

符号含义已知 / 未知说明
$\omega$角频率先验给定（或给定频段后粗估）这正是与 D1 两派的根本区别：target-based 要已知航迹波形［1］，noise-based 不预设波形［1］；本课题预设"单频周期"这一条结构信息
$\gamma$幅值未知，待估检测阶段当作待检参数；估计阶段给 $\hat\gamma$ 与相对误差
$\theta$初相位未知，待估初相位盲区是阵列设计的直接动机［7］
$T$观测时长设计变量与"变尺度后的等效采样率"一起决定可分辨的最低频率

频段与量级的三处锚点（三处口径不同，必须分别引用）：

来源频段幅值用途
频域电磁法应用面［6］mHz ~ kHzpT ~ μT说明"跨度大"这个困难，不用来定本课题参数
磁通门低噪声窗口［2］1–100 Hz噪声底约 1 pT/√Hz前端选型与噪声底预算
本课题初设$f_s\in[0.1,\ 10]$ Hz$\gamma$ 取 0.1–10 nT，默认 1 nT待导师确认实测对象后改

⚠️ 「极低频」在本课题里不是 ITU 的 3–30 Hz 定义，也不是 E3 的 mHz–kHz 全段，而是"前端能覆盖、算法能变尺度"的交集。写论文时必须先声明取哪一段，否则 SNR 数字没有意义（D5 的"噪声底 + 带宽 + 屏蔽"三件套同理［2］）。

三、噪声模型：两档可切换

A 档｜高斯白噪声（基线，必须先跑通）

$$n(t)\sim\mathcal N(0,\sigma^2),\qquad \text{PSD } N_0=\sigma^2/f_s \ \text{(单边)}$$

  • 作用：与教科书结论对齐、给阶段 2/3 的阈值扫描提供干净对照。
  • 局限：真实极低频背景不是白的，只用白噪会高估算法性能。

B 档｜$1/f^{\alpha}$ 有色噪声（贴近实测，主力档）

$$S_n(f)\propto\frac{1}{f^{\alpha}},\qquad 0<\alpha<2$$

  • $\alpha$ 取 0.5 / 1.0 / 1.2 / 1.5 四档，与 Sun 等的仿真设置一致［4］，便于将来同条件对照。
  • 生成方式：频域整形（白噪 FFT → 乘 $f^{-\alpha/2}$ → IFFT），或分数阶积分；两条路都要固定随机种子以便复现。
  • 依据：环境噪声为 $1/f^{\alpha}$ 有色噪声，且地质噪声特征与铁磁目标几乎相同［1］；低频段主敌是 $1/f$ 漂移与 Barkhausen 噪声，不是白噪［2］。

C 档｜实测替换（最终档，暂缺）

导师组的实测磁场噪声数据到位后，用实测序列替代 B 档生成器，直接当 $H_0$ 样本源。这是把"仿真论文"变成"结合科研"的唯一途径。

可选附加项（先不实现，留接口）：50 Hz 工频及谐波、脉冲型干扰、量测噪声中的量化噪声。加之前先问一句"它会不会改变结论"，否则只会让表变长。

算例（把"SNR"和"$\sigma$"绑死，避免两处各说各话）

取 $\gamma=1$ nT、$s(t)=\gamma\cos\omega t$，则信号均方 $\overline{s^2}=\gamma^2/2=0.5\ \mathrm{nT^2}$。若目标 $\mathrm{SNR}_E=-20$ dB，则

$$10\lg\frac{\gamma^2/2}{\sigma^2}=-20\ \Rightarrow\ \sigma^2=\frac{0.5}{0.01}=50\ \mathrm{nT^2}\ \Rightarrow\ \sigma\approx7.07\ \mathrm{nT}$$

反过来，给定 $\sigma$ 就能算出该跑的 SNR 点。这张反算表要写进代码，不要手算。

五、SNR 定义：写死两套，说清换算

主口径（本课题主线，与［4］同构）

$$\mathrm{SNR}_E=10\lg\frac{\sum_i s(i)^2}{\sum_i n(i)^2}$$

整段序列的能量比，不依赖带宽、实现最简单，便于与 Sun 等的 $P_d$ 曲线对照［4］。

对照口径（仅用于引用 ★[2] 时换算）

$$\mathrm{SNR}_{\rm band}=10\lg\frac{\bar{s^2}}{N_0 B}$$

带内信号功率与带内噪声功率之比，与 ★[2] 的窄带 SNR（$10\lg(p_a/p_n)$、0–10 Hz 带限）同类［7］。

三条硬规矩

  1. 论文里只出现一种主口径，另一套只作换算说明，绝不混用。
  2. 任何 SNR 数字后面必须跟：噪声类型与 $\alpha$、带宽 $B$、采样率、时长 $T$、判据。
  3. 不与文献数字横向比较。★[2] 报频率门限 −23 dB、参数估计门限 −21 dB［7］，★[3] 报 −15 dB 下 $P_d=72\%$［4］，两者噪声模型、带宽、SNR 定义、判据全不同；本课题若给 −18 dB，那是自己条件下的 −18 dB。

方法学注脚（可直接写进论文）：随机共振类工作常用"SNR 提升多少 dB"作为卖点，但 A5 已指出 SNR 在 $D\to0$ 时发散，故 SNR 增益本身不足以证明 SR 发生［3］。同理，本课题也不应把"SNR 增益"当唯一指标——$P_d$ 在固定 $P_{fa}$ 下的值才是可比量。

六、二元假设

内容数据生成判据输出
$H_0$仅噪声：$x(t)=n(t)$A 档白噪或 B 档色噪；C 档到位后改用实测判"有"即为虚警，统计 $P_{fa}$
$H_1$信号 + 噪声：$x(t)=s(t)+n(t)$同上 + $\gamma\cos(\omega t+\theta)$，$\theta$ 在 $[0,2\pi)$ 上随机判"有"即为检出，统计 $P_d$
  • 每次试验独立重抽噪声与 $\theta$，每点 ≥100 次（★[3] 用 100 组［4］，可对齐）。
  • 阈值由 $H_0$ 样本单独标定，不得用 $H_1$ 数据调阈值——这是 ROC 是否可信的分水岭。
  • 记录方式：每点存 $(P_d,\ P_{fa},\ \mathrm{SNR},\ \text{条件})$，复现输出/ 下存 JSON，便于阶段 4 直接绘图。

七、待导师补齐的四件事（写进周报）

  1. 实测背景噪声数据（时间序列或 PSD），用来替换 B 档 → C 档。
  2. 目标信号的真实频段与幅值量级，用来锚定 §四 的 $f_s$ 与 $\gamma$。
  3. 前端传感器的型号与噪声底规格（磁通门 / TMR / 其他），用来校验 §四 最后两行。
  4. 验收时希望看到的指标形式（$P_d$ 固定 $P_{fa}$？还是给定 SNR 报误差？），用来定 §五 的主口径。
