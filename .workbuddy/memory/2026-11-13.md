## 追加：★[2] Sensors 2023 阵列 Duffing 论文深度精读（同日）
- 用户给出 13 点精读要求（含作者思路重建、数学推导从零、实验设计、脆弱假设、一周复现、反例、后续调研、follow-up idea），按上下文锁定 ★[2] Yang Y 等 Sensors 2023, 23(17):7598。
- 全文来源：本地 PDF 经 workbuddy-pdf 提取 + PMC10490661 官方 HTML 抓全文（curl 需 `--ssl-no-revoke`，且 Windows 原生 Python 不认 Git Bash 的 /tmp，路径要用工作区绝对路径）。公式、Eq.1–17、Table 1–6、实验参数均已核对。
- 产出：`论文精读-阵列Duffing_Sensors2023.md`（13 节，严格区分【原文】【文献】【推断】【猜测】）、`复现实验-阵列Duffing临界阈值.py`（向量化 RK4 + Poincaré 截面判态，三段实验）。主清单顶部加指向。
- 关键发现 1：论文 Eq.(17) 漏平方根，正确为 gamma = sqrt(0.73² − λ1λ2)；Eq.(11)/(14) 的 0.73 应平方。用 λ1=0.7414, λ2=0.7183 验证得 0.01876 ≈ 论文 0.0188，θ 解交集 −128° 亦吻合。
- 关键发现 2：实测（h=0.02, T=400, 初值(0,0), 无噪声）分岔在 λ=0.735→0.740，h=0.1/0.05/0.02/0.01 一致；论文 0.72/0.73 偏低约 0.01。工作点扫描：λ=0.72 相位覆盖 64.9%/虚警 0%，0.73 覆盖 100%/虚警 10%，0.735 虚警 90%。论文的「全相位覆盖 + 噪声免疫」在我的条件下不可兼得；但条件与论文不同，只能算敏感性检验，不能断言论文错误。
- 关键发现 3：γ² = 0.73² − λ1λ2 = 3.52e-4 属灾难性相消，λ 扰动 5e-4 即让根号内变负；解释论文参数估计门限比频率检测高 2 dB 的另一半原因。
- 关键发现 4：Melnikov 方法只能给「进入混沌」的下阈值，不能给「混沌→大周期」的上阈值（学位论文结论）；Chaos 2025, 35(11):113101 进一步证明 Melnikov 判据之外仍有混沌。故 0.72 只能经验标定。
- 后续调研：作者自己 2025《仪器仪表学报》46(10):218-229 换成阵列三稳系统（−18 dB，井斜误差<1°），摘要直说双稳「相位覆盖不全导致检测偏差」，构成自我修正；KG-Duffing（EURASIP JASP 2025, 10.1186/s13634-025-01279-8）证明纯噪声可造伪周期虚警；Sensors 2026, 26(17):5545（轴频磁场，与毕设高度相关）引用本文并批评阵列「计算开销大、频率分辨率受阵列步长限制」，−30 dB 准确率 88.33%；OpenAlex cited_by_count=10。
- Follow-up idea：chaos-CFAR，把 λ 从固定常数变成扫描轴，用同帧数据的 H0 代理构造零假设曲线，在给定 Pfa 下在线选工作点，输出 p 值与 γ 的贝叶斯后验（绕开病态求差），把「最低可检测 SNR」重定义为 Pd/Pfa 约束下的统计量。

- 方案做成三态自适应，写进 `index.html` 末尾内联 JS（node --check 通过）：① `127.0.0.1:8765` → 不改链接，服务端实时渲染，nav 显示绿色「Markdown 实时排版已启用」；② `file://` 双击 → 运行时把 `.md` / `.md#anchor` 改指向同名 `.html` 静态副本，顶部显示淡蓝提示；③ 其它 http（单文件预览）→ 显示黄条 + 「打开排版版索引」按钮。envbar 文案由 JS 按环境注入。
- 新增 `build_static.py`：自动从 index.html 提取全部相对 .md 链接，用 `serve_index.render_md` 生成同名 .html（当前 4 份：3 份根目录主文档 + `文献/00-下载索引.html`）。支持 `--check` 检查副本是否过期。静态副本的「返回索引」按目录层级算相对路径（子目录用 `../index.html`），「查看源码」指向同目录 .md，顶部加 staticnote 说明它是副本、改动后需重跑。
- 新增 `start_index.bat`（纯 ASCII 内容 + `%~dp0`，避开中文路径编码问题）：检查 py → 跑 build_static.py → 端口未占用才起服务 → 自动开浏览器 → 5 秒后退出。`serve_index.py` 增 `render_md(..., back, raw, note)` 与 PAGE 的 `{back}/{note}` 占位；`_port()` 只取纯数字参数，修掉被 build_static.py --check 导入时 `--check` 被当端口解析的 ValueError。
- 渲染器其它增强：md 内相对链接的 Windows 反斜杠自动转正斜杠；引入 MathJax 3（jsDelivr CDN）渲染精读文档里的 `$...$` 公式，离线时静默降级为原始 LaTeX；`?raw=1` 仍返回 text/markdown。
- 校验：55 本地链接 / 16 外链 / 0 失效锚点；4 个 .md 链接的 .html 副本全部存在；10 处链接改写模拟全部命中；8765 下 4 份 md 返回 text/html 含表格，raw 返回 text/markdown，PDF 返回 application/pdf；build_static.py --check 报「无（全部为最新）」。
- 约定：以后改动任一 Markdown 后运行 `py build_static.py`（或直接双击 start_index.bat，它会自动重建）；长期看资料优先用 8765 实时版。
