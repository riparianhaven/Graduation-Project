一个先说的结论：没有"拿来就用"的判据

本阶段最重要的产出不是某个判据跑通了，而是三个判据的本机实测表现，以及一次由实现 bug 引起的假警报及其修正：

判据理论预期本机实测判定
Poincaré $p_{std}$周期态低、混沌态高周期 0.010，混沌 0.67，阈值 0.08 干净分开✅ 主判据
多尺度熵 MsEn周期态熵低且趋稳周期 0.037，混沌 0.635，噪声下 ΔM 稳定 +0.60~+0.84✅ 副判据

一次翻案记录：早期实现写成 $K=\mathrm{median}_c\,\mathrm{corr}(n,M_c)$（带符号取中位数），得到"混沌 −0.031 < 周期 +0.008"的方向反转假象，一度判为"判据失效、弃用"。修正为逐 c 取绝对值 $K=\mathrm{median}_c|\mathrm{corr}(n,M_c)|$ 后，两态次序与含噪表现均符合理论——这是实现 bug，不是判据或论文的问题。但修正后仍有两条限制：幅度远小于理论 1（须本机定分界）、跃变带内非单调（对间歇不敏感）。

这不是"论文错了"——B3 的 0-1 test 在其原始条件下有效；本系统是相量驱动的强周期混沌 + 有限长序列（750 点），条件不同。复现检验的是 claim 的敏感性与边界，不是裁定论文对错。

Q1｜相图分割法、二分法、Lyapunov 指数法各自的局限？

B1 引言把当时的判据家底盘了一遍，结合本机实测的失败案例：

判据原理局限出处
相轨迹 / 时序目测看轨道是否整圈绕行"受诸多因素影响、受实验人员主观影响，精度低误差大"；本机用 $\maxx>1.2$ 把所有状态判成周期态（混沌轨道本来就偶尔跑远），虚警 100%B1 + 本机
Melnikov / Shilnikov解析算混沌参数范围只能说"可能处于混沌"，不能确定一定处于B1
Lyapunov 指数度量轨迹收敛/发散率"算法复杂，且容易受到噪声的影响"，精确值难以得到B1
相图分割 / 二分 / Poincaré几何或统计定位跃变"仍具有一定局限性"；本机 Poincaré $p_{std}$ 好用，但阈值随步长 ±0.005 漂B1 + 阶段 2
0-1 test直接吃序列输出 0/1逐 c 取绝对值后次序正确，但幅度小、带内非单调，见 Q2B3 + 本机

结论：目测与幅值门限不能当自动判据；Lyapunov 理论黄金但工程昂贵；可计算判据（Poincaré / MsEn）必须本机标定，且多判据交叉验证优于单打一。

Q2｜为什么需要多尺度熵？0-1 test 的 K 在含噪时怎么修正？

为什么多尺度：单尺度样本熵只看一个时间尺度上的复杂度，而混沌与周期的区别在多个尺度上才充分暴露。MsEn 先把序列按尺度 $\tau$ 粗粒化

$$y_j^{(\tau)}=\frac{1}{\tau}\sum_{i=(j-1)\tau+1}^{j\tau}x_i,$$

再在每个尺度算 SampEn$(m=2,\ r=0.2\,\mathrm{SD},\ \tau)$，B1 取 $\tau=1,2,4,8$。系统进入周期态后熵值明显变小且趋于平稳——B1 特别强调"只看熵值大小不准确，要看平稳性"（其图 2 在 $r=0.605$ 处熵值极小但仍在波动，此时并未相变）。本机实测：噪声 σ=0→0.20 全档，MsEn 混沌−周期差 $\Delta M=+0.60\sim+0.84$，符号不翻，是可靠副判据。

0-1 test 怎么修：答案是先修实现 bug——绝对值要取在每个 c 的相关系数上。理论 $K\approx0$（周期）/$K\approx1$（混沌）；早先实现为 $\mathrm{median}_c\,\mathrm{corr}(n,M_c)$（带符号），出现方向反转的假象：

σ旧 K(混)旧 K(周)**新 \K\(混)****新 \K\(周)****新 Δ\K\**MsEn ΔM
0.00−0.0307+0.00710.03160.0074+0.0241+0.5970
0.02——0.01760.0077+0.0099+0.8368
0.05−0.0025+0.00730.05520.0076+0.0476+0.7591
0.10−0.0420+0.00730.04230.0074+0.0349+0.7969
0.20+0.0118（翻号）+0.00710.02910.0074+0.0217+0.7148

根因：Gottwald–Melbourne 的 $K_c=\mathrm{corr}(n,M_c(n))$ 在有限长序列下会因相位抵消出现负值，负值不是"反混沌"，而是伪影；对带符号的 $K_c$ 取中位数，负值就把统计量拉反。正确写法是
$$K=\mathrm{median}_c\big(|\mathrm{corr}(n,M_c(n))|\big)$$
修正后：两态次序与理论一致（混沌 0.0316 > 周期 0.0083），含噪五档 Δ\|K\| 全部为正、不再翻号。这不是"论文被推翻"，而是本机实现 bug 的修正。

但仍有两条限制，不能当成拿来就用的判据：① 幅度远小于理论 1（本机相量驱动强周期混沌 + 750 点短序列 + Poincaré 强相关采样，把 K 压低），不能搬用 0.5 门限，须本机定分界；② λ 精扫显示带内非单调（如 λ=0.745 处 \|K\|=0.0559 反弹，而 pstd/MsEn 已重置），对"带内间歇"不敏感。故推荐组合是 pstd 主 + MsEn 副 + 0-1 test 第三票。

Q3｜同频不同初相位为什么漏检？阵列怎么补？盲区区间在哪？

同频时内驱与信号按 Eq.(8) 合成相量 $C=\sqrt{\lambda^2+\gamma^2+2\lambda\gamma\cos\Delta\theta}$。相变要求 $C\ge C_{trig}=0.73$，解出允许失配

$$\Delta_{\max}(\lambda,\gamma)=\arccos\frac{C_{trig}^2-\lambda^2-\gamma^2}{2\lambda\gamma}$$

超出 $|\Delta\theta|>\Delta_{\max}$ 就是硬盲区——所有判据都会说"没信号"。$\lambda=0.72,\ \gamma=0.02$ 时实测 $\Delta_{\max}=60.69°$（与 ★[2] 完全一致），单振子覆盖 33.7%，三振子 0°/±120° 理论覆盖 100%。三振子把盲区缩成"任一振子的 $\Delta_{\max}$ 覆盖区"。

盲区噪声退化（本阶段补的 Q7 剩余动作，$\theta$ 全周 36 点 × 3 个 σ 档）：

σ单振子检出三振子 OR 检出
0.002/36 (6%)13/36 (36%)
0.052/36 (6%)14/36 (39%)
0.155/36 (14%)17/36 (47%)

⚠️ 口径差异必须解释：理论 33.7%/100% 用的是合成幅值 $C\ge0.73$ 的解析判据（只看相量几何）；实测 6%/36% 用的是 $p_{std}<0.08$ 的动力学判据 + 200 s 短窗 + 单种子。相量达标 ≠ 瞬态已收敛到周期吸引子，故实测更保守。但三振子 OR 持续 2–3 倍高于单振子，"多振子扩大覆盖"的方向成立。绝对覆盖率须在阶段 4 用足够长序列 + 多种子统计重标。

两个 γ_c 不要混（这是本阶段修正的一处口径）：

  • 同相触发 $\gamma_c=C_{trig}-\lambda=\mathbf{0.0100}$：同相时只要信号这么大就能翻；
  • 全相位覆盖 $\gamma\approx\mathbf{0.0196}$：任意初相位都能检出（对应 $\Delta_{\max}=60°$，三振子无缝覆盖）；
  • 干净仿真中 $p_{std}$ 首个翻转在 $\gamma=0.0175$，落在两者之间——判据翻转点 ≠ 相量几何阈值，因为还要等吸引子收敛。

三、判态伪代码（过关产出，x(t) → 0/1）

函数 判态(x, 噪声σ, 标定参数):
    输入: x[0..N-1]        # 稳态段观测（丢弃瞬态后）
          σ                # 噪声强度（用于选重标定门限）
          pstd_th(σ), MsEn_th(σ)   # 本机 H0 标定门限，不是理论值
    步骤:
      1. 去均值 → xc
      2. # 主判据：Poincaré 截面离散度
         p = xc[每 2π 采样一次]     # 需内驱相位参考（嵌入式用参考时钟）
         pstd = std(p[后半段])
      3. # 副判据 A：多尺度样本熵
         MsEn = [ SampEn(x 粗粒度 τ) for τ in (1,2,4,8) ]
         平稳性 = std(MsEn 后半窗) < 容差
      4. # 副判据 B：0-1 test（逐 c 取绝对值，周期态 K 小 → 与 pstd 同向）
         K = median_c |corr(n, p_c(n)² + q_c(n)²)|
      5. # 融合：三判据表决（门限均须本机按噪声重标定）
         vote = (pstd < pstd_th) + (MsEn低 且 平稳) + (K < K_th)
         return 1 if vote >= 2 else 0
    输出: 0=混沌/无信号, 1=大尺度周期/有信号

门限必须在目标噪声条件下用 $H_0$ 样本重标定（阶段 4 做 $P_{fa}$ 时一并给）。三振子阵列对三路各自执行本函数，再按 OR / 多数表决融合。

四、边界声明（数字必须连条件一起抄）

本阶段条件是 $\lambda=0.72$、$h=0.02$ s、$T=200\sim300$ s、干净/白噪、Poincaré + MsEn 判据、单种子（盲区实验）。MsEn 取 $m=2,\ r=0.2\mathrm{SD},\ \tau\in\{1,2,4,8\}$，$r$ 选错会全塌成 0。0-1 test 用 $K=\mathrm{median}_c|\mathrm{corr}(n,M_c)|$（30 个 c，逐 c 取绝对值），幅度偏小的结论只在本系统条件下成立，不外推到 B3 的原始条件。各文献 SNR 门限实验条件互不统一，不可横向比较。
