1. 模型与方程#

1.1 从 Holmes 型 Duffing 振子到强耦合#

原文式 (1) 是标准 Holmes 型：

\[ \ddot{x} + \xi\dot{x} - x + x^3 = F\cos t \]

做时间尺度变换 \(t=\omega\tau\)（原文式 2），把固定频率 1 rad/s 换成可调的 \(\omega\)：

\[ \ddot{x} + \omega\xi\dot{x} - \omega^2(x-x^3) = \omega^2 F\cos(\omega t) \]

这一步决定了后面所有参数的量纲：\(\omega\) 越大，同一个 \(F\) 作用越猛，步长必须跟着缩。

强耦合结构（原文式 4）是两个振子同时耦合恢复力与阻尼力：

\[\begin{split} \begin{aligned} \ddot{x}_1 + \omega\xi\dot{x}_1 + \omega^2\xi k(x_1-x_2) + \omega k(\dot{x}_1-\dot{x}_2) - \omega^2(x_1-x_1^3) &= \omega^2\big[F\cos(\omega t)+s(t)+n(t)\big]\\ \ddot{x}_2 + \omega\xi\dot{x}_2 + \omega^2\xi k(x_2-x_1) + \omega k(\dot{x}_2-\dot{x}_1) - \omega^2(x_2-x_2^3) &= \omega^2 F\cos(\omega t) \end{aligned} \end{split}\]

1.2 差模方程：强耦合到底做了什么#

两个方程相减（令 \(\Delta=x_1-x_2\)，注意不除以 2）：

\[ \ddot\Delta+(\omega\xi+2\omega k)\dot\Delta+\omega^2(2\xi k-1)\Delta+\omega^2(x_1^3-x_2^3)=\omega^2\big[s(t)+n(t)\big] \]

这一个式子就能解释原文第 4 节的两整节经验曲线：

  • 刚度项的符号由 \(2\xi k-1\) 决定。\(k<k_c=1/(2\xi)=0.714\) 时它是负的， 差模仍是双阱——脉冲激励下两振子各奔一个阱，”差分”就等于把信号扔掉。 这正是原文「\(0<k<1\) 时检测失效」的数学原因。

  • 阻尼项多了 \(2\omega k\)。等效阻尼比 \(\zeta=(\xi+2k)/\big(2\sqrt{2\xi k-1}\big)\)，\(k=10\) 时等于 2.87，过阻尼。 弱耦合（\(k\to0\)）时差模是欠阻尼双阱，会振铃；强耦合把它改成过阻尼单阱跟随。 这才是”能恢复波形”的真正原因——不是耦合变大，是差模换了一套阻尼。

xi = 0.7
print(f"k_c = 1/(2*xi) = {1/(2*xi):.4f}   ← 差模由双阱变单阱的门限\n")
print(f"{'k':>7}{'2ξk−1':>9}{'ζ':>8}{'准静态增益':>12}  判定")
for k in (0.3, 0.5, 0.7, 0.714, 1, 3, 10, 100):
    d = 2*xi*k - 1
    if d <= 0:
        print(f"{k:>7.3f}{d:>9.3f}{'—':>8}{'—':>12}  负刚度：差模仍是双阱")
    else:
        z = (xi + 2*k) / (2*np.sqrt(d))
        print(f"{k:>7.3f}{d:>9.3f}{z:>8.2f}{1/d:>12.4f}  {'过阻尼' if z>1 else '欠阻尼'}")

准静态下忽略非线性项，\(\Delta \approx s/(2\xi k-1)\)。\(k=10\) 时增益 \(1/13\)。 这个增益小于 1，所以差分通道不会凭空提高灵敏度——信号和噪声被同比例压低，SNR 不变。 第 4 章会看到，这正是”必须靠限带来换信噪比”的原因。

实测增益比 \(1/13\) 还低一些，因为 \(x_1^3-x_2^3\approx3x^2\Delta\) 提供了一部分负刚度修正。 下面验证无信号时两振子是否严格同步。

T, h = 40e-6, 1e-9
t = np.arange(int(round(T/h)) + 1) * h
print(f"时长 {T*1e6:.0f} us，步长 {h*1e9:.0f} ns，共 {len(t)} 点，"
      f"约 {T/(2*np.pi/5e6):.1f} 个激励周期")

so0 = S.simulate(t, batch=1)
print(f"无信号时 max|ẋ1−ẋ2| = {np.abs(so0).max():.2e}   ← 浮点零，不是「很小」")
so1 = S.simulate(t, drive=lambda tt: 0.0*tt, batch=1)
print(f"零驱动同解：max|ẋ1−ẋ2| = {np.abs(so1).max():.2e}")

时长 40 us，步长 1 ns，共 40001 点，约 31.8 个激励周期

无信号时 max|ẋ1−ẋ2| = 1.16e-10   ← 浮点零，不是「很小」

零驱动同解：max|ẋ1−ẋ2| = 1.16e-10

结果是机器精度 0。这意味着任何非零的 \(\dot x_1-\dot x_2\) 都由 \(s(t)\) 或 \(n(t)\) 直接引起， 没有基线偏置要标定——原文说它”不受初始状态限制”即指此。第 4 章会看到，这个性质让 \(P_{fa}\) 可以解析算出。
