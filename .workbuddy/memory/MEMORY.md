## ★[2] Sensors 2023 复现的定论（2026-11-24）
- **ν 不是输入参数，是 ω/R 的别名。** 待测 ω 未知时 ν 不需要预设：扫 R 到相变点，那一点的 R 就是 ω（原文步骤 4 原话）。ν 事后才被确认等于 1。`nu=omega/R` 只存在于公式推导里——**2026-11-24 晚已把项目里的解析写法 `simulate()` 全部删除，代码中不再存在 `nu=omega/R` 这一行**；唯一内核是 `simulate_seq(sig, R, dt, lam, beta)`，只吃采样序列 + `h₁=R·dt`。详见 `02-阶段二/变尺度中ν与R的辨析.md`。
- **无信号标定也走同一个盲测内核**：喂全零序列 `SIG0=np.zeros(1)` + `R0=1.0`，此时 `h1 = R0*dt = dt`，数值时间轴与物理时间轴重合，等价于"只有内驱"。这样阈值标定与含信号检测是同一个函数、同一段 RK4，不存在"两套积分器各算一遍"的口径问题。`m==1` 走 Python float 标量快路径（比数组路径快约 11 倍）；Poincaré 取截面用精确 2π 线性插值。
- **内核单一来源 = `tools/kernel_src.py`**（2026-11-24 深夜定案）。`KERNEL_SRC` 保存 `simulate_seq` 源码正文；`build_stage2/3/4_notebook.py` 把它拼进 notebook（notebook 保持自包含、不 import），`s2-jupyterbook/_src/s2sim.py` 用 `load_kernel()` exec 进自己的命名空间。**改内核只能改这一处**，然后重新生成 + 重跑。`tests/test_kernel_contract.py`（16 项）钉死：禁 `def simulate(`、每份 notebook 恰好一个内核、内核正文必须逐字等于 `KERNEL_SRC`（防止"改了生成器没重新生成"或"手改 notebook 被覆盖"）、冒烟值 0.3522/3.5e-6、标量 vs 向量路径 1e-12 一致。含内核的 5 份 notebook：`learn/2,3,4,all` + `复现-2`。
- **两个刻意保留的 `simulate_*`（不是漏改）**：`simulate_fixed`（阶段 5 定点复刻，存在意义就是和浮点内核比量化代价）、`c2sim.simulate(t, drive)`（C2 强耦合双振子，外部序列驱动，没有待测频率未知的问题）。阶段 4 的旧 `simulate_mc` 已改成 `pstd_mc()`——只把「γcos+噪声」折成序列再调 `simulate_seq(R=1,h1=h)`，**噪声中点由"整步保持"变"相邻样本均值"**，pstd 中位差 3~6%，Pd 在阈值附近动几个百分点（最低可检测 SNR 仍是 −11.0 dB）。
- **2026-11-24 晚：扫 R 段已在三份 notebook 里全部改成盲测**（`learn/2.ipynb`、`learn/all.ipynb`、根目录 `复现-2-...ipynb`）——检测函数签名 `simulate_seq(sig, R, dt, lam, beta)` 里没有 ω、没有 ν，只吃采样序列。新增两条硬结论：**① 频率选择带宽只有 ±0.1%**（判据 1e-2；三频 10/7.3/3.7 实测完全一致 = 由阻尼与恢复力决定，与频率无关）；**② 全域穷举必漏**——4.9%/格时离真值最近格点偏 0.88%，最低 pstd 停在 1.4e-2，那是伪相变不是真共振；必须先由采样序列自身（FFT，误差 ≤0.005%）给初值，再在 ±1% 内按 0.05%/格细扫。三频最终误差 ≤0.012%（抛物插值）。**旧"ν 容差 ±0.5%"是 600 s 短窗估计，长窗（150 周期）下真实带宽是 ±0.1%，引用时用后者。**
- **带宽测量必须单路做**：三振子取 min 会把别的振子在锁频态上的伪相变捞进来，把带宽边界弄糊（实测从 0.20% 糊成 0.55%）。单路 β=−120° 才干净；阵列分解只用于"有信号/无信号"判决，实测 β=0 → 0.38、β=−120° → 2.2e-4、β=+120° → 0.51（即论文图 5 的消融）。
- **真实 λ_c ≈ 0.7335**（0.7332 混沌 / 0.7336 周期；0.7334 是刀锋点，两种积分写法分别给 3e-6 与 0.38 → 报带不报点）。旧说 0.735/0.736 偏高，主因是**粗网格 0.005 + 短时窗**，不是判据本身。
- **两条必须记住的数值红线**：
  ① Poincaré 采样必须精确落在 τ=2πk 做线性插值。按步数取整时（h=0.02 → 2π/h=314.159）周期态 pstd 从 3.2e-6 被抬到 1.5e-2，**压掉 3.5 个量级动态范围**（判读没翻转，但裕度全失真）。
  ② **λc 附近瞬态长达上千秒**：T=400 时 λ=0.735/0.738/0.739 都读成混沌，T=1200 仍有个别点不收敛（0.7342 给 7.9e-3），要到 T=3000 才全部收敛到 3e-6。据此写出的「跃变带内混沌/周期交替＝间歇混沌/双稳」是伪结论。
- 动态范围拉开后的新结论：伪相变（R≠ω）的 pstd **最低只到 3e-2**（准周期游走），真共振 3e-5，**差 3 个量级**；门限从 0.08 收紧到 1e-3 后，扫 R 只剩真值通过。但**相干指数 ρ 分不开**（0.9954 vs 其余最高 0.9931，只差 0.002）——判频只能用 pstd 的绝对量级，不能用波形相似度。这把"变尺度扫 R 定频率"从"定不了"推进到"能定"。
