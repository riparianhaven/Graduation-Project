# 精读 D1：磁异常检测方法综述（MST 2021）

> **一句话定位**：这不是提出新算法的原创论文，而是一篇 **Topical Review（专题综述）**。它解决的是「领域知识怎么摆」的问题——把 1940 年代到 2018 年散落的磁异常检测（MAD）方法，按「是否需要对目标与磁强计的相对运动做假设」重新切成两派，逐法交代原理、检测灵敏度、优缺点，并指出共同的实时性与低 SNR 瓶颈。对本毕设而言，它是「国内外研究现状」的分类骨架 + 信号/噪声模型假设的来源，**不是**可以照抄的检测方法。

## 1. 它到底解决什么问题

必须分三层答，否则容易把「综述的贡献」误当成「算法的贡献」。

### 1.1 领域共同的根本困难【原文】

- 地磁场 $T$ 通常**远大于**铁磁目标的感应磁场 $B$（$T \gg B$），磁强计测到的是总场 $B_s=B+T$。
- 被检测的磁异常信号「是地磁噪声的万分之几」（§4 原文 *tens of thousands of parts of geomagnetic noise*），**时域上直接检测太弱**（§4：*It is too weak for the target to be detected directly in the time domain*）。
- 环境磁噪声多为**有色噪声**（$1/f^{\alpha}$），而主流 OBF 方法假设**高斯白噪声**；影响地磁噪声的因素多、变化无规律，难以去除。
- **地质噪声**（局部地质结构非均匀引起的局部磁场异常）的特征「与铁磁目标几乎相同」（§4），是最难对付的混淆源。
- 于是所有方法本质上都在做同一件事：**在尽量保留磁异常信号的前提下，最大限度压掉地磁噪声**，把这个矛盾转成某个可计算的统计量再设阈值。

### 1.2 这篇综述自己解决的问题【原文 + 推断】

- **【原文】** 把近年 MAD 方法归成两类，给出更清晰的分类与原理梳理（§1、摘要）；补上磁偶极子模型与 OBF 家族 3/4/5 基的演化脉络；对四种噪声派方法逐一讨论「原理与检测灵敏度」；末尾以表 1、表 2 列优缺点并提出未来方向。
- **【推断】** 它真正解决的是**选型问题**：面对一堆名字互不相干的方法，给出一条决策规则（见 §2），并首次把「**实时性 / 计算量**」和「**噪声是否高斯白**」摆到与「检测率」同等显眼的位置（§4、表 1/2）。这对工程选题比单纯的精度对比更有用。
- **【原文】** 明确承认的未解问题：能量函数、自适应算法、多点迭代等定位算法「需要更多计算」，必须改进或创新算法才能让 MAD 真正落地应用（§4 末）。

### 1.3 每个被综述的方法各自解决什么【原文】

| 方法 | 它补的是哪个漏洞 |
|---|---|
| 磁偶极子模型 + CPA | 把「目标是什么形状的信号」变成可写的解析式，让后续匹配检测有模板 |
| 标准 OBF（3 基） | 单磁强计下，把淹没在高斯白噪里的信号投影到低维基空间，用能量函数显著提 SNR |
| 5 基 OBF | 梯度计（双磁强计差分）消除共模噪声，且不依赖相对偶极子位置 |
| 4 基 OBF | 5 基计算太重，在目标-探头距离较近时降维，减计算量、提鲁棒性 |
| AR 白化 + 匹配滤波 | 修 OBF 在**非高斯 / 有色噪声**下失效的问题 |
| 最小熵 / 差分熵滤波 | 绕开 OBF 的庞大计算，用「噪声分布是否被目标扰动」直接判有无 |
| 高阶过零 HOC | 进一步把计算压到**无需任何乘法**，适合低功耗实时硬件 |
| 随机共振 SR | 反过来**利用噪声**增强弱信号，且不需要信号的确定性参数 |
| 小波变换 | 用多尺度稀疏性去非高斯噪声，尽量保留目标信息 |

## 2. 全局分类框架：两派与唯一判据

**【原文】** D1 摘要与 §2、§3 给出的分界：

| | **基于目标 target-based** | **基于噪声 noise-based** |
|---|---|---|
| 出发点 | 分析目标信号的典型模式，从目标磁场特征反推目标 | 分析磁强计噪声的统计特性，认为异常来自铁磁目标引起的扰动 |
| 关键假设 | 磁强计与目标**存在相对运动**，且目标运动服从特定跟踪时间模式 | **不能**对目标与磁强计的互运动做任何假设 |
| 目标先验 | 需要（偶极子模型、直线运动、特征时间 $\tau_0$ 已知） | 不需要，「自适应于磁背景」，实现更简单、计算量更小 |
| 代表方法 | 磁偶极子模型 → OBF 3/5/4 基 → AR 白化改进 | 最小熵/差分熵滤波、HOC、随机共振、小波变换 |
| 代价 | 计算量大、需白化、不宜实时 | 多数受低 SNR 限制，或只对一类信号有效 |

**【推断】** 一句话记住判据：**能不能预先写出「目标经过时信号长什么样」**。能 → 用匹配类（OBF）；不能 → 只能盯噪声分布有没有被扰动。这也解释了为什么两派的失效模式完全不同：一派怕「模型不匹配」，另一派怕「扰动太小、被噪声淹没」。

**【文献】** D1 之后，2025 年 arXiv:2504.05212《On multipolar magnetic anomaly detection》明确把 Zhao et al. (2021) 的两派分类当作传统划分，并指出**还应加上第三类：基于人工智能/深度学习的方法**（SVM、全连接网络、自编码器、CNN/RNN/注意力等），同时点名这类方法「极度依赖数据、难以给出检测性能保证」。**【推断】** D1 成文于 2020 年，未纳入这一支；写 2026 年的开题报告时，现状小节应自行补上 AI 派，不能直接照抄 D1 的两分法当作「完整分类」。

## 3. 共同前提：从总场到可检测信号

**【原文】** §2.1，公式 (1)–(5)：

磁偶极子在空间任意点的场

$$\mathbf{B}=\frac{\mu_0}{4\pi}\left[\frac{3(\mathbf{M}\cdot\mathbf{r})\mathbf{r}}{r^5}-\frac{\mathbf{M}}{r^3}\right] \tag{1}$$

其中 $\mathbf{M}$ 为目标磁矩，$\mathbf{r}$ 为目标到测点的矢量。总场 $B_s=B+T$，由 $T\gg B$ 得 $|B_s|^2\cong |T|^2+2\mathbf{B}\cdot\mathbf{T}$，再用 $\sqrt{1+2x}\cong 1+x$ 线性化：

$$B_s\cong T+\frac{\mathbf{B}\cdot\mathbf{T}}{T},\qquad S=\frac{\mathbf{B}\cdot\mathbf{T}}{T} \tag{2–5}$$

**这一步是全部 target-based 方法的立足点**：标量磁强计的读数等于目标场在**地磁方向上的投影**。

**【原文】** 场强随距离衰减（式 (1) 与 $R_0^{-3}$ 的前置因子）；定义 **CPA（closest proximity approach，最近接近点）** 为信号最强处，MAD 系统检测到的最大信号强度点即为 CPA。传感器尺寸相对 CPA 距离足够小时，CPA 前后一小段时间内的响应才跟随真实异常信号、保证有效定位。

**【原文】** §2 开头列出的 target-based **三条硬前提**：

- (a) 测量点到目标的距离**远大于目标自身尺寸** → 才可等效为磁偶极子；
- (b) 目标沿**直线**穿过磁传感器方向，且磁矩的**大小与方向保持不变**；
- (c) 目标**特征时间 $\tau$ 已知且预设**，$\tau_0=R_0/v$。

**【原文】** 另加一条隐含前提：OBF 分解算法**要求背景噪声满足高斯白噪声假设**，因此实际应用须先对环境数据做算法修正（§2 开头），这正是 §2.3 改进算法的动机。

## 4. 基于目标（target-based）的方法

### 4.1 标准 OBF 分解（Ginzburg / Frumkis 2002）

**【原文】** §2.2 的谱系：Anderson 1940 年代末首创 OBF → Mori 1990 用自适应权函数改善弱 SNR → 2002 年 Ginzburg/Frumkis 提出标准 OBF 分解 → 2004 年讨论梯度计的 5 基 → 再讨论 5 基降 4 基（简化计算并增强稳定性）。

**核心思想**：把目标信号写成少数几个**标准正交基函数的线性组合**，把「在时域找波形」变成「在基空间求系数」，用系数平方和构造能量函数。

$$S=\frac{\mu_0 M}{4\pi R_0^3}\sum_{n=1}^{4} b_n\varphi_n(w),\qquad w=\frac{vt}{R_0}=\frac{t}{\tau_0} \tag{6,7}$$

$w$ 是沿测线轨迹的无量纲坐标。经 Schmidt 正交化得三个归一化基（式 (8)）：

$$f_1(w)=\sqrt{\tfrac{128}{3\pi}}\,\frac{w^2}{(1+w^2)^{5/2}},\quad f_2(w)=\sqrt{\tfrac{128}{5\pi}}\,\frac{w}{(1+w^2)^{5/2}},\quad f_3(w)=\sqrt{\tfrac{24}{5\pi}}\,\frac{1-\tfrac53 w^2}{(1+w^2)^{5/2}}$$

$$S=\frac{\mu_0 M}{4\pi R_0^3}\sum_{n=1}^{3} a_n f_n(w),\qquad \int_{-\infty}^{+\infty} f_i f_j\,dw=0\ (i\neq j) \tag{9,10}$$

系数由投影得到、能量函数由系数构造（式 (11)(12)）：

$$\alpha_j=\Big(\frac{\mu_0 M}{4\pi R_0^3}\Big)^{-1}\int_{-\infty}^{+\infty} f_j(w)S\,dw,\qquad E=\alpha_1^2+\alpha_2^2+\alpha_3^2$$

**【原文】** 流程（图 5）：信号 → 滑窗 OBF 分解 → 求系数 → 能量函数 → 峰值判决。图 6 的对照中，滑窗宽度为 $-6\le w\le 6$；被高斯白噪污染的信号在能量函数上 SNR 显著提升，**能量函数峰-峰值对应目标位置**。

> **【推断·勘误提醒】** 本地 PDF 抽取文本中式 (10) 第二行作 $\int f_i^2 dw=0$，与「归一化正交基」自相矛盾（归一化应给出非零常数/1）。疑为原文排版或 PDF 抽取问题，引用时以标准 OBF 文献（D1 [38] Ginzburg et al., Sens. Actuators A, 2002, 102: 67–75）为准，不要照抄这个 0。

### 4.2 三种基的数量怎么选

| 配置 | 适用条件【原文】 | 优点（表 1 / §2.2） | 代价 |
|---|---|---|---|
| **3 基** | 单磁强计，线性航迹 | 提高 SNR、提取有效磁信号 | 只对高斯白噪理想 |
| **5 基** | 梯度计（两台磁强计差分，$S=S_1-S_2$，式 (13)–(16)） | 基可**任意取向**、**不依赖相对偶极子位置**，通用性好；基线长/CPA 距离比可在大范围变化 | 计算负担重（表 1：*Heavy calculation burden*） |
| **4 基** | 目标与磁强计距离很近时（Yarotsky 1992 提出，Ginzburg 用式 (17)(18)） | 减少计算量、**提高鲁棒性**、更贴合实测 | 仅在该近距离条件下成立 |

**【原文】** 5 基由 Schmidt 正交化得到 6 个、舍去 1 个而来；4 基的四个函数 $v_1\ldots v_4$ 的分母为 $(1+w^2)^{7/2}$，梯度信号写作 $G(w)=\frac{\mu_0 M\delta}{4\pi R_0^3}\sum_{n=1}^{4}C_n v_n(w)$。图 8、图 9 分别给出 5 基、4 基的能量函数对照。

### 4.3 改进 OBF：AR 模型白化滤波（Sheinker 2007）

**动机【原文】**：标准 OBF 在**高斯白噪声下最优**，对非高斯白噪效果不佳；而实测环境磁噪声「多数情况下是非高斯白噪」（§2.3）。因此**先分析并高斯化环境磁噪声，是 OBF 优化的前提**。

$$x(n)=\sum_{k=1}^{M}a_k x(n-k)+\omega(n) \tag{19}$$

把地磁噪声看作满足 $1/f^{\alpha}$（$0<\alpha<2$）功率谱的 $M$ 阶 AR 过程，$\omega(n)$ 为白噪声。重排为白化变换（式 (20)），用 **Levinson–Durbin 递推**求系数 $a_k$，把有色噪声变成白噪声。

> **最关键的一步（式 (21)）**：白化滤波会**同时扭曲目标信号**（原文：*the target signal will be distorted*）。所以不能只白化输入，必须**把 OBF 本身也预先白化**：
> $$\xi_i(n)=h(n)\times f(n)$$
> 其中 $h(n)$ 为白化系统传递函数、$f(n)$ 为原 OBF。整体链路是：输入 → 白化滤波 → **与已白化基的匹配滤波** → 检测输出（图 10）。图 11 显示，对 $1/f^{\alpha}$ 噪声，白化后的能量函数比传统 OBF 的目标特征更突出。

**【推断】** 这是全文最容易被读漏、也最值得学的一处工程思想：**任何预处理只要改变了信号通道，就必须同等地改变模板/基**，否则匹配失配。它和本毕设 notebook 里「换可观测量结论就塌」是同一类方法论教训。

## 5. 基于噪声（noise-based）的四种方法

**【原文】** §3 开头的共同设定：假设噪声统计特性的变化由铁磁目标引起；方法自适应于磁背景、**无需目标先验**，实现简单、计算量小。

### 5.1 最小熵滤波（Sheinker 2008）与差分熵（Liu 2015 / Tang 2018）

**原理**：真实磁噪声的 PDF 近似高斯、由均值与方差控制。由 $M$ 个样本估 $\mu,\sigma^2$（式 (22)(23)），再对区间积分得离散概率 $p(x_i)$（式 (24)），滑窗 $L$ 个样本的熵为

$$I(x_i)=-\sum_{m=i-L+1}^{i}p(x_m)\log p(x_m) \tag{25}$$

**目标出现 → 分布偏离高斯 → 熵下降 → 低于阈值即判有目标；阈值按 Neyman–Pearson 准则确定**（§3.1.1）。图 12 给出滤波前后对照。

**差分熵版本**：用**一对相隔一定距离、置于相对安静磁环境的磁强计**做差分，用核平滑估计差分信号的 PDF（式 (26)(27) 的 $H(x)=-E_x[\log p_x]$），靠差分消掉共模地磁/外部场干扰。Tang 2018 用 2000 个采样点做实验（图 13）。

**限制条件【原文】**

- 噪声 PDF 需**近似高斯**（否则式 (22) 的概率估计失真）；
- **窗长 $N$（或 $L$）必须折中**：太大 → 检测器对目标不响应；太小 → 过于敏感，背景噪声被误判为目标（§3.1.2 明文）；
- 阈值依赖 NP 准则，即需给定虚警率并标定量；
- 表 2 / §4：计算量小、**目标移动速度慢时效果更好**，适合实时；但**受低 SNR 限制**；
- 差分版额外要求：一对探头 + 相对安静的磁环境。

### 5.2 高阶过零 HOC（Sheinker 2012）

**原理**：平稳随机信号的高阶过零与其**自相关函数 / 功率谱**紧密相关，因此可用「过零计数」代替谱分析来分辨信号差异。

$$q(n)=\begin{cases}1,&x(n)>0\\0,&x(n)\le0\end{cases},\quad D=\sum_{n=2}^{N}[q(n)-q(n-1)]^2,\quad R=\frac{D}{N-1} \tag{28–30}$$

引入差分算子 $\nabla x(n)=x(n)-x(n-1)$、$k$ 阶递推 $\nabla^k x(n)=\nabla[\nabla^{k-1}x(n)]$（式 (31)(32)），定义速率增量 $\Delta_k(R)$（式 (33)），最后用类 $\chi^2$ 判别函数（式 (34)）：

$$\psi^2=\sum_{k=1}^{K}\frac{[\Delta_k(R_{\text{window}})-\Delta_k(R_{\text{background}})]^2}{\Delta_k(R_{\text{background}})}$$

$K$ 为参与比较的 HOC 阶数。图 14 用 8000 个采样点，目标深埋噪声，HOC 输出的目标峰显著高于噪声峰。

**限制条件【原文】**

- 必须先有**干净的背景速率序列** $R_{\text{background}}$ 作基线（判别函数以它为分母与参照）；
- 表 2 / §4：**受低 SNR 限制**（*Limited by low SNR*）；
- 优势：**不需要任何乘法运算**、实现简单、功耗低，只依赖噪声背景、不需目标信号假设，对实时应用与地震前兆研究很有吸引力。

### 5.3 随机共振 SR（Wang 2017/2018）

**原理【原文】**：往非线性势阱系统里加**适当强度的噪声**，使弱周期信号在势阱间跃迁，从而放大弱信号的幅值功率——「用噪声增强信号」。用 **Langevin 方程**描述，最常用经典**双稳 SR**（图 15）。做法是：先实验取得真实地磁噪声样本并仿真典型异常信号，再用 **Runge–Kutta 法**寻找合理的系统参数；异常信号出现时输出**状态发生切换、标准差显著增大**（图 16a/b/c）。

**限制条件【原文】**

- 表 2：优点是**不需要信号的确定性参数**；缺点是 **"Only works for one class"** —— §4 措辞更完整：只能对**一类异常信号**给出近似性能的检测；
- 需真实噪声样本 + 仿真典型信号 + RK 调参，**参数依赖具体场景**；
- §4：适用于**有色噪声**，可提高输出 SNR、易实现。

### 5.4 小波变换（Zhang 2011；Zhou 验证高斯化）

**原理【原文】**：小波是时间–尺度的局部变换，通过伸缩平移做多尺度分析。把小波系数矩阵处理成概率分布序列，其熵反映系数矩阵的稀疏度，称**小波熵**；用稀疏度抑制无关分量以提取信号、发现「小而短」的异常。Zhou 以海洋噪声为例验证小波变换的「Gaussian effect」；具体做法用 **db3 小波做 4 尺度分解**，取**最低频分量**即可有效去噪并保留目标（§3.4 正文所引图示；D1 全文图号止于 16，此处原文未另编号）。

**限制条件【原文】**

- 表 2 / §4：降噪效果好，但**强噪声下以信号幅度衰减为代价**（*loss of signal amplitude attenuation*）；
- **【推断】** 幅度衰减对「只要判有无」影响小，对「要估幅值」是硬伤——这与本毕设「参数估计精度」指标直接冲突，是选型时必须记下的一条。

## 6. 限制条件总表（逐法汇总）

| 方法 | 必须成立的假设 / 前提 | 明确写出的失效边界 | 实时性 / 计算量 |
|---|---|---|---|
| 磁偶极子 + 标量投影 | $T\gg B$；距离 $\gg$ 目标尺寸；磁矩大小方向恒定 | 近场、大目标、磁矩翻转 → 偶极近似与线性化失效 | — |
| 标准 OBF（3 基） | 直线匀速航迹；$\tau_0=R_0/v$ **已知**；高斯白噪 | 非高斯/有色噪声下效果不佳；$\tau_0$ 失配则模板失配 | 计算量大 |
| 5 基 OBF | 双探头梯度计；需差分构造 | 计算负担重 | 重（表 1 唯一明写缺点） |
| 4 基 OBF | 目标—探头**距离很近** | 不满足近距离条件时降维无依据 | 比 5 基省、鲁棒性提升 |
| AR 白化 + 已白化基 | 噪声近似高斯、可用 $1/f^{\alpha}$（$0<\alpha<2$）AR 过程建模；需先估 AR 系数 | 噪声不满足 AR/$1/f^{\alpha}$ 假设时白化失效；**忘记同步白化基会导致匹配失配** | 增加前置滤波开销 |
| 最小熵 / 差分熵 | 噪声 PDF 近似高斯；虚警率给定；窗长 $N$ 需折中；差分版需双探头 + 安静磁环境 | $N$ 过大漏检、过小虚警；**低 SNR 受限** | 计算量小，适合实时；慢速目标更佳 |
| HOC | 需干净背景速率序列作基线 | **低 SNR 受限** | 无需乘法、低功耗，最适合实时 |
| 随机共振 | 双稳势阱模型；需真实噪声样本 + RK 调参 | **只对一类异常信号有效**，泛化差 | 易实现 |
| 小波变换 | 目标信息集中在低频、系数具稀疏性 | 强噪声下**幅度衰减** | 中等（多尺度分解） |

**【原文】** §4 的跨方法结论，可直接作为开题报告「现有方法局限」小节的四条骨架：

1. **OBF**：能量函数显著提 SNR，且**对目标磁矩不敏感**（故得到理想脉冲形状）；但**计算密集、不适合实时应用**；两台磁强计可消共模噪声；因 OBF 更适合白噪声而地磁周围多为有色噪声，**使用前必须先白化**。
2. **最小熵 + HOC**：前者计算量小、目标慢速时效果好，后者无需乘法、简单低功耗；但**两者都受低 SNR 限制**。
3. **随机共振**：用噪声增强提高输出 SNR，不需确定性参数、适用于有色噪声；但只能对一类异常信号给出近似检测性能。
4. **小波**：降噪好，但强噪声下牺牲幅度。

**【原文】** 未来方向：找到「**最大限度保留磁异常信号 + 最大限度去除地磁噪声**」的方法是研究重点；定位算法（能量函数、自适应、多点迭代）计算量大，须在现有方法基础上改进或创新才能实用化。

## 7. 放回本毕设：能拿什么、不能拿什么

### 7.1 直接可用

| 用途 | D1 提供的东西 |
|---|---|
| 开题报告「国内外研究现状」 | 两派分类框架（表 1/2 可直接改写成小标题）、1940s–2018 方法谱系、§4 四条局限 |
| 环节 1「输入信号」建模 | $B_s=B+T$、$T\gg B$ 下的投影 $S=\mathbf{B}\cdot\mathbf{T}/T$、CPA、$R_0^{-3}$ 衰减 |
| 环节 1「噪声模型」 | $1/f^{\alpha}$ 有色噪声（$0<\alpha<2$）、地质噪声特征与目标几乎相同、非高斯 |
| 环节 4「相变判据」的对照组 | 熵滤波 / HOC / SR / 小波都是「把目测换成可计算统计量」的同类思路；HOC 的 NP 阈值、窗长折中可类比 $p_{std}$ 阈值与 $T$ 的折中 |
| 工序 4 嵌入式实现的动机 | 「OBF 计算密集、不适合实时」正是要上 FPGA 的直接理由；HOC「无需乘法」是定点化思路的现成范例 |
| 课题背景定位 | MAD 是**被动检测**、地磁场既是「激励源」（磁化铁磁体）又是「最大干扰」 |

### 7.2 必须守住的边界

**【原文 + 检索核实】** 对本地 D1 全文做词频核对：**Duffing / chaos / chaotic / Lyapunov / bifurcation / Poincaré 均出现 0 次**；machine learning / deep learning / SVM / CNN 也均为 0（"neural networks" 仅 4 次，且都出现在随机共振的应用领域举例里）。据此：

- **【推断】** D1 的两派里**没有混沌振子这一支**。它的「target-based」特指**磁偶极子空间波形匹配**（OBF），前提是空间直线航迹与已知 $\tau_0$；本课题的 Duffing 阵列假设的是**已知频率的时间周期信号**，靠非线性系统跨分岔阈值做窄带相干检测。二者「基于目标」的含义不同，**不要把课题硬塞进 D1 的任何一派**，写现状时宜表述为「在两派之外，基于非线性系统相变的弱信号检测构成另一条路线」，再引 A/B/C 组文献。
- **【文献】** ★[2] 作者组 2021 年前作（Sensors, 21(9):3011）恰是「随机共振 + 混沌相变协同检测」，说明 **D1 §3.3 的 SR 与本课题的 Duffing 同源**（非线性势阱 + 噪声辅助），但机制不同：SR 靠噪声促成势阱间跃迁并放大周期分量，Duffing 靠策动力幅值跨临界阈值引发混沌 → 大尺度周期态相变。这条脉络可用来把课题自然接进 MAD 大背景，见 [★[2] 精读](论文精读-阵列Duffing_Sensors2023.md)。
- **【推断】** 两处有意思的结构呼应：① D1 target-based 要求 $\tau_0=R_0/v$ **已知**，★[2] 的**变尺度扫 $R$** 本质上也是在搜这个未知尺度，只是搜的是频率而非空间特征时间；② D1 §4 说地质噪声「与目标特征几乎相同」，正是本课题必须报 $P_d/P_{fa}$、不能只报检测率的原因——混淆源与目标不可分辨时，$P_{fa}$ 才是硬约束。
- **【推断】** D1 所有方法面向**单次通过式的空间异常脉冲**（能量函数找峰、CPA 定位），本课题面向**持续存在的极低频周期信号**（判有无 + 估幅相）。信号模型不同，$SNR$ 口径不同，**D1 里任何检测灵敏度数字都不可横向搬用**；项目约定「SNR 门限必须连 $P_d/P_{fa}$ 与实验条件一起给」在这里同样成立。

## 9. 一页速记

- **性质**：综述，不是算法论文；贡献是分类、选型与局限梳理。
- **判据**：能否预设目标—探头的相对运动与信号波形？能 → OBF 匹配；不能 → 噪声统计突变。
- **共同敌人**：$T\gg B$、$1/f^{\alpha}$ 有色噪声、地质噪声与目标同特征、时域太弱。
- **OBF 族**：3 基单探头 / 5 基梯度计 / 4 基近距离降维；改进靠 AR 白化，且**基也要白化**。
- **噪声族**：熵（NP 阈值、窗长折中）、HOC（无需乘法、需干净背景基线）、SR（用噪声、只对一类）、小波（降噪好、幅度衰减）。
- **四条硬限制**：OBF 不宜实时且需先白化；熵与 HOC 受低 SNR 限制；SR 泛化差；小波强噪下丢幅值。
- **对本课题**：拿现状骨架、信号/噪声模型、对照组与 FPGA 动机；**不拿**方法归属——D1 全文没有混沌振子，也没有 AI 派。
