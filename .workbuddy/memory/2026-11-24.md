**关键技术结论（要长期记住）**
1. **ν 不是输入参数，是 ω/R 的别名。** 待测 ω 未知时 ν 不需要也不能预设：扫 R 到相变点，那一点的 R 就是 ω（原文步骤 4 原话）。ν 是事后被确认等于 1 的量。写成 `nu=omega/R` 只是"验证模式"，数据驱动盲测时代码里不含 ω。
2. **修正后真实临界阈值 λ_c = 0.733**（0.732 仍混沌 pstd=0.329；0.734 精确归零）。旧版 0.736 含 Poincaré 采样伪迹。
3. **Poincaré 采样必须精确落在 τ=2πk 时刻做线性插值**，否则 h 不整除 2π（如 h=0.02 时 2π/h=314.159）会让采样相位每周期漂移 0.003 rad，把周期态误判成混沌（A=0.74 时 pstd=0.10 的假象）。
4. **盲测复现 ω=10/7.3/3.7**，误差 +0.00% / +0.07% / −0.14%（代码中不含 ω，只吃采样序列 + h1=R·dt）。
5. **图 5 四幅消融全复现**：无信号 / R=1 / R=10 β=0° 全混沌，仅 R=10 β=−120° 周期。
6. **表 2 与步骤 3 数学上不自洽**：R=10 → h₁=1 s → 每周期 6.28 步 → RK4 数值发散，原文参数组合跑不出结果。
7. **三路 λ 对不上同一 C_trig**：0.7342/0.7335/0.7256，极差 0.0086；导致 γ 估 0.0139（−31%）、θ 估 −138.3°（偏 18.3°）。根因："相变只由合成幅值 C 决定"只是近似，实际还依赖 λ 的绝对值。
8. **ν 容差约 ±0.5%**；扫 R 多重检验 N=41 时总虚警 `1−(1−0.05)^41 = 87.8%`，必须做 Bonferroni 或 FDR 校正。

- 阈值标定改喂**全零序列 `SIG0=np.zeros(1)` + `R0=1.0`**——此时 `h1 = R0*dt = dt`，数值时间轴与物理时间轴重合，等价于"只有内驱"。无信号标定与含信号检测现在是同一函数、同一段 RK4。
