0. 一句话版本

【推断】 这一条要你亲手造一个「放在悬崖边上的非线性比较器」：先写出方程并数值跑通，再找到那个让输出从乱跳变成整圈绕行的临界推力，最后把这条边界当成后面所有检测与参数估计的标尺。没有这一步，第 3 条「依据相变判别信号有无」就没有判别依据，第 4 条的信噪比曲线也没有横坐标。

直觉先于公式：把振子想成一个在双势阱里被周期性推搡的小球。推力小，它在两个谷之间无规则地翻来翻去（混沌态）；推力越过某个值，它开始跟着外力一步一拍地绕大圈（大尺度周期态）。待测的微弱周期信号，就是最后那一点点推力。所以「检测」在物理上不是把信号放大，而是让系统跨过一条分界线——这条线的位置必须自己标定出来。

2. 第一件事：建立模型

2.1 方程与每一项的物理含义

【原文】 标准 Holmes–Duffing（★[2] Eq.1）：

$$\ddot{x}+k\dot{x}-x+x^3=\lambda\cos(\omega t)$$

【原文】 母本改用五次恢复力（★[2] Eq.2、Eq.3）：

$$\ddot{x}+0.5\dot{x}-x^3+x^5=\underbrace{0.72\cos(t+\beta)}_{\text{内置参考策动力}}+\underbrace{\gamma\cos(t+\theta)}_{\text{待测弱信号}}+n(t)$$

项名字作用取值
$\ddot x$惯性状态变量 $x$ 是「位移」，$\dot x=y$ 是速度，二阶方程写成两个一阶方程才能积分—
$0.5\dot x$阻尼耗散，没有它系统不会收敛到吸引子$k=0.5$【原文】
$-x^3+x^5$改进恢复力对应势函数 $V(x)=-\tfrac14 x^4+\tfrac16 x^6$，双阱、阱壁比标准 Duffing 更「陡」【原文】论文理由是标准 Duffing 对正弦弱信号响应不敏感
$0.72\cos(t+\beta)$内驱 / 参考提供已知频率（$\omega=1$ rad/s）与已知相位 $\beta$ 的相干参考$\lambda_c=0.72$，初值 $x(0)=\dot x(0)=0$【原文】
$\gamma\cos(t+\theta)+n(t)$待测信号 + 噪声只有与内驱同频的分量才能相干叠加$\gamma\ll\lambda$，$\theta$ 随机

【原文】 论文说 0.72 是「经大量实验验证」的经验值，并宣称合成幅值达到 0.73 就触发相变。【推断】 这句话本身就是这一条课题要你补的洞：既然是经验值，就该由你自己的数值实验重新标定一次，并写清标定条件（步长、时长、初值、判据、噪声有无）。精读文档第 6.2 节说明，这个方向的阈值没有现成的 Melnikov 解析式可用，数值标定不是偷懒，而是唯一可行的路。

2.2 一个省事又关键的代数技巧

【原文】 两个同频余弦可以按 Eq.(8) 合成相量：

$$\lambda\cos(t+\beta)+\gamma\cos(t+\theta)=A\cos t-B\sin t,\quad
\begin{cases}A=\lambda\cos\beta+\gamma\cos\theta\\ B=\lambda\sin\beta+\gamma\sin\theta\end{cases}$$

$$C^2=\lambda^2+\gamma^2+2\lambda\gamma\cos(\theta-\beta)$$

【推断】 这一行是全文枢纽，也是 notebook 里最值得亲手验证的一行：它把「会不会相变」从一个动力学问题，变成一个只要比大小的不等式 $C\gtrsim 0.73$。往正方向用得到相位窗口与阵列设计，往反方向用得到参数估计方程。写代码时把两路余弦合成 A、B 再积分，比直接算两个 cos 更快，也顺带检验了推导。

3. 第二件事：相轨迹演变规律

【文献】 判别状态的可观测量不止一种：相图目测、Lyapunov 指数、0-1 test（B3）、多尺度熵（B1）、Poincaré 截面离散度。课题原文只说「分析相轨迹演变规律」，没规定用哪种，这正是自由度，也是坑。

【推断 + 复现数据】 在 notebook 第 3、5 节会看到同一批数据被两种判据处理：

判据结果结论
稳态段 $\max\lvert x\rvert>1.2$ 判为周期态所有 $\lambda$、所有相位、所有噪声强度全部判成周期态，虚警 100%不可用。混沌轨道本来就偶尔跑得很远
Poincaré 截面后半段 $p_{std}<0.08$周期态 ≈0.015，混沌态 0.16–0.63，分离度一个数量级以上可用，且完全自动、可写进代码

这条失败值得单独记进毕设：论文里「观察输出状态」这四个字，换一个可观测量结论就塌了。判态必须是可计算统计量，不能靠眼睛。

【推断】 「演变规律」要写清三层，别只贴两张图：

  1. 小 $\lambda$：轨道在两个势阱间不规则跳跃，Poincaré 点散成一片 → 混沌态；
  2. 越过临界 $\lambda_c$：轨道被内驱锁定，绕两阱外侧做整圈运动，Poincaré 点收敛到一个点 → 大尺度周期态；
  3. 跃变是突变而非渐变：$p_{std}$ 从 0.59 掉到 0.015，中间没有平滑过渡（notebook 第 4 节曲线）。这个「悬崖」正是检测器灵敏度的来源，也是阈值必须标定的原因。

4. 第三件事：临界阈值

4.1 定义要写死

【推断】 「临界阈值」在本课题里至少有三种含义，论文里混着用，写毕设时必须先声明你用哪个：

记号含义数值
$\lambda_c$无待测信号时，内驱幅值使系统跳到大尺度周期态的分岔点论文 0.72 / 0.73；本复现实测 0.735–0.740
工作点 $\lambda_0$实际检测时预置的内驱幅值，取略小于 $\lambda_c$论文 0.72
触发合成幅值 $C_{trig}$内驱 + 待测信号相量合成后，刚好越过边界的总幅值论文 0.73

【原文】 相变边界写成 $C^2\ge 0.73^2$（Eq.11 印成 $\ge0.73$，Eq.12 反推应带平方）。代入 $\gamma=0.02$ 得相位窗口半宽

$$\cos(\theta-\beta)\ \ge\ \frac{0.73^2-0.72^2-0.02^2}{2\times0.72\times0.02}=0.48958
\ \Longrightarrow\ |\theta-\beta|\le 60.69^\circ$$

这正是三振子（$\beta=0^\circ,\pm120^\circ$）「全相位覆盖」设计的全部依据。

4.2 标定流程（notebook 第 4 节照此执行）

  1. 固定 $k,\omega,h,T,$ 初值、无噪声、$\gamma=0$；
  2. 在 $\lambda\in[0.60,0.85]$ 上以 0.005 扫描，每次独立积分；
  3. 用 $p_{std}$ 判态，找连续三点首次进入周期态的位置 → 粗阈值；
  4. 在粗阈值附近加密到 0.001 精扫；
  5. 换 $h=0.1/0.05/0.02/0.01$ 重做，确认跃变位置不随步长漂移；
  6. 加噪声重做，说明阈值是否还是同一个。

【复现数据】 四种步长（0.1 / 0.05 / 0.02 / 0.01 s）下跃变都落在 0.730–0.740 这 0.01 宽的窗口内，具体边界随步长与吸引域有 ±0.005 抖动。以 0.001 精扫：$0.734$ 已是周期态、$0.735$ 又回混沌、$0.736$ 起才稳定进入周期态——跃变带内存在间歇混沌与双稳，阈值应报一个「带」而不是一个点。稳定起点约 0.736，比论文 0.72 / 0.73 高约 0.01。这不是「论文错了」，而是经验阈值依赖仿真条件：论文用 Ode4、$h=0.1$ s、含噪、目测相图，本复现用 RK4、$h=0.02$ s、无噪、Poincaré 判据。写论文时把自己标定的阈值和论文值并列，注明条件，不要只抄一个数。

4.3 阈值一偏，后面全偏

【推断 + 复现数据】 工作点离分岔多远，直接决定两个互相拉扯的指标（notebook 第 8 节）：

$\lambda_0$三振子相位覆盖率（$\gamma=0.02$）纯噪声虚警率（$\sigma=0.20$）判读
0.700≈0%0%太保守，几乎检不到
0.720≈65%0%论文工作点：零虚警但覆盖不全
0.730≈100%10%覆盖达标，开始虚警
0.735≈100%90%噪声本身就把振子推过界

【复现数据】 notebook §8 用 $T=300$ s、独立随机种子重跑同一实验，得到 0.720: 57.5% / 0%，0.730: 97.3% / 2.5%，0.735: 98.6% / 75%，趋势完全一致，绝对值随仿真时长与随机种子波动。写论文时以你自己那一次运行的数字为准，并注明 $T$、帧数与噪声口径。

【推断】 所谓「对噪声免疫」不是系统性质，而是「工作点离分岔够远」的性质，代价是灵敏度。这两个 claim 是同一条曲线上不可兼得的两端——这也是精读文档第 13 节 chaos-CFAR 想法的由来，以及本课题要交「最低可检测信噪比」时必须连 $P_{fa}$ 一起报的原因。

4.4 估幅公式里的一颗地雷

【原文】 论文 Eq.(17) 印成 $\gamma=0.73^2-\lambda_1\lambda_2$。【推断 + 亲手验算】 正确形式是

$$\boxed{\ \gamma=\sqrt{0.73^2-\lambda_1\lambda_2}\ }$$

用论文自己的 $\lambda_1=0.7414,\ \lambda_2=0.7183$ 验算：$0.5329-0.532548=0.000352$，开方得 0.01876，正是 Table 3 报的 0.0188；不开放根号差 53 倍。照原文复现会直接卡死。【推断】 更要命的是灾难性相消：两个约 0.53 的数相减得到 0.00035，$\lambda_1$ 只要偏 $5\times10^{-4}$，根号里就可能变负。notebook 第 9 节把这条敏感性画出来。

7. 常见坑清单（按踩到的顺序）

  1. 用 python3 跑不动：本机 py 指向 Python 3.13 且带 numpy 2.4.6 / matplotlib 3.11，python3 那个解释器没装科学计算包。统一用 py。
  2. 把两个 cos 直接相加却忘了同频：只要频率不同，相量合成就不成立，变尺度那一节必须换回双频形式直接积分。
  3. 噪声离散化漏掉 $\sqrt h$：白噪声是 $\sigma\,dW$，一步的增量是 $\sigma\sqrt h\,N(0,1)$，直接加 $\sigma N(0,1)$ 会让有效噪声强度随步长变化。
  4. 瞬态不够长：前 200 s 丢掉，Poincaré 点再取后半段，否则起振过程会把周期态也判成混沌。
  5. 用 $\max|x|$ 或目测判态：见第 3 节，虚警 100% 的教训。
  6. 拿 0.73 当普适常数：它是经验值，换步长、换噪声、换恢复力都得重标。
  7. Eq.(17) 照抄原文：漏平方根，且病态相消，见 4.4 节。
  8. 变尺度忘了噪声也变：$R=10$ 时等效采样率降到 1 Hz，对 0–10 Hz 噪声必然混叠，论文没讨论这一点【推断】。
  9. 把跃变当成一个点：精扫带内 0.734 周期、0.735 混沌、0.736 起才稳定。报阈值要报带，并注明判据与步长【复现数据】。
  10. 扫 $R$ 的锁频伪相变：notebook §6 里 $R=8/9/9.5/12/13$ 同样出现低 $p_{std}$，且内驱分量占比与 $R=10$ 几乎一样。换一个可观测量也没能救回「哪个 R 相变，$\omega$ 就是 R」这一推断，必须换成能看见待测信号 $\nu$ 分量的统计量【复现数据 + 推断】。
  11. 从小样本曲线上抠一个 SNR 门限：16 帧的二项标准误约 ±12%，加上 $\lambda=0.72$ 的相位窗口天花板，$P_d$ 非单调是正常的。先做单调性检查，再决定要不要报数字【复现数据】。

【推断】 第 5、10、11 条其实是一条：可观测量决定结论。§5 的 $\max|x|$ 失效、§6 的内驱相干占比分不开锁频、§10 的固定 $p_{std}$ 阈值在强噪声下退化——三次都指向「混沌/周期二分类的信息量不够」。写毕设方法章节时，这句话比任何一张漂亮的相图都值钱。

8. 写进论文时可以直接用的表述（示范）

【推断，示范文字，非原文】 本文采用改进恢复力的 Duffing 振子作为检测模型，其动力学方程为 $\ddot x+0.5\dot x-x^3+x^5=\lambda\cos(t+\beta)+\gamma\cos(t+\theta)+n(t)$。以四阶 Runge–Kutta 法数值求解（$h=0.02$ s，$T=400$ s，初值取零），并以 Poincaré 截面 $x(2\pi n)$ 在稳态后半段的标准差 $p_{std}$ 作为状态判据：$p_{std}<0.08$ 判为大尺度周期态，否则判为混沌态。在无噪声条件下对内驱幅值 $\lambda$ 扫描，得到混沌态向大尺度周期态跃变的临界值 $\lambda_c=\text{（填你实测值）}$；在 $h=0.1/0.05/0.02/0.01$ s 四种步长下跃变区间一致，说明该阈值对积分步长不敏感。后续检测将工作点预置于略低于 $\lambda_c$ 处，待测同频信号与内驱的相量合成幅值越过该边界时，系统发生相变，据此判别信号有无并在此基础上估计幅值。

把「填你实测值」换成 notebook §4 打印的数字，并在脚注里写明与论文 0.72/0.73 的条件差异，这一段就成立了。
